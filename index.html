Architecture

Built for reliability.

A robust two-tier database architecture that keeps your data isolated, secure, and blazing fast. WebAssembly-based SQLite (sql.js) provides rapid local querying, while each company gets its own fully isolated database file.

  • Offline-first local storage — no internet required
  • Two-tier DB isolation (master.db + per-company DBs)
  • Double-entry posting engine (GAAP compliant)
  • Vector-fidelity PDF printing via Playwright
  • SHA-256 cryptographic audit chain
database-architecture.sql 
-- Master Database (Global)
CREATE TABLE master.db (
  companies     TABLE,
  app_settings  TABLE
);

-- Per-Company Isolation
CREATE DATABASE {companyId}.db
  LOCATION 'Documents/JVS FinTech/{Name}/'

  -- Accounts & Ledgers
  account_groups   → Assets, Liabilities
  ledgers          → Parties, Banks, Tax

  -- Transactions
  sales_invoices   → Auto GST calc
  purchase_bills   → ITC tracking
  vouchers         → Payment, Receipt

  -- Inventory
  stock_items      → Batch, Expiry
  stock_journals   → Adjustments

  -- Audit
  audit_log        → SHA-256 chained
